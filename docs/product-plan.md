# 知错图谱产品拆解

## 一句话定位

知错图谱是一款面向学生的 AI 错题学习助手，通过拍照识别错题、分析错因、映射知识点并动态生成知识图谱，帮助用户从“记录错题”升级到“理解薄弱点并精准复习”。

## 目标用户

- 初高中学生：日常作业、考试复盘、考前查漏补缺。
- 大学生：课程复习、题库练习、知识体系梳理。

## 比赛版闭环

1. 上传错题图片或手动输入题目。
2. OCR / 视觉模型识别题干。
3. 用户确认并修正题目内容。
4. 蓝心大模型分析错因、知识点和练习。
5. 前端保存错题并累计更新知识图谱。
6. 点击薄弱点进入复习小测。
7. 小测结果反向调整薄弱分。

## 评分点对应

- 创新性：错题与知识图谱联动，不只是保存错题或问答壳。
- 界面交互：拍题、分析、图谱、错题本、小测形成连续路径。
- 应用价值：面向高频学习场景，痛点明确。
- 大模型应用：OCR/视觉识别、错因分析、知识点映射、练习生成均通过 API 实现。
